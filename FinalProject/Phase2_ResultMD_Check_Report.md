### 5.1 数学公式检查

#### ✅ 协整均衡方程（第3.2节）
```
ln(P_rb,t) = α + β ln(P_hc,t) + ε_t
```
**评价**: ✅ 正确

#### ✅ OU过程公式（第4.1节）
```
X_{t+1} - X_t = θ(μ - X_t) + σ·ε
```
**评价**: ✅ 正确

#### ✅ Z-score公式（第5.1节）
```
Z_t = (ε_t - μ_ε) / σ_ε
```
**评价**: ✅ 正确

#### ✅ VECM公式（第3.6节）
```
ΔY_t = αβ'Y_{t-1} + Σ Γ_i ΔY_{t-i} + μ + ε_t
```
**评价**: ✅ 正确

#### ✅ VAR公式（第3.3节）
```
Y_t = Φ_0 + Φ_1 Y_{t-1} + ... + Φ_p Y_{t-p} + ε_t
```

**评价**: ✅ 正确
